LEARNING TARGET

I can order Negative Fractions with Benchmarks, and explain and check my reasoning.

01 · LEARN

Build the idea

Mark zero and equally spaced whole-number ticks. Partition each interval into equal parts for the denominator. Negative values are left of zero on a horizontal line and below zero on a vertical line. A number farther right is greater. Among negative numbers, the value closer to zero is greater. Use a common denominator or familiar benchmarks to compare negative fractions.

WORKED EXAMPLE 1 · Constructed response

Draw a horizontal or vertical number line. Plot and label -8, 0, and 6.

  1. Mark zero and equally spaced whole-number ticks.
  2. Partition each interval into equal parts for the denominator.
  3. Negative -8 is left of or below 0
  4. 6 is right of or above 0.
  5. Use equal intervals.
  6. State the result in the form requested: -8 < 0 < 6; unit steps.
-8 < 0 < 6; unit steps
WORKED EXAMPLE 2 · Multiple select

Temperatures are -5 °C and -3 °C. Select all true comparisons.

A. -5 is warmer than -3.

B. -5 < -3

C. -3 lies to the right of -5 on a number line.

D. -5 > 0

  1. A number farther right is greater.
  2. Among negatives, the number closer to zero is greater.
  3. Thus -3 is warmer and is farther right.
B, C - -5 < -3; -3 lies to the right of -5 on a number line.
02 · PRACTICE

Start with foundations, then apply the idea and explain your reasoning. Select answers below or record them on paper.

  1. Constructed response

  2. Constructed response

    Compare -3 ___ -3 using <, >, or =. Sketch a number line to justify.

  3. Constructed response

    Draw a horizontal or vertical number line. Plot and label -6, 0, and 2.

  4. Constructed response

    Compare -2 ___ -1/2 using <, >, or =. Sketch a number line to justify.

  5. Constructed response

    Draw a horizontal or vertical number line. Plot and label -2/3, 0, and 4/3.

  6. Constructed response

    Compare -3/5 ___ -4/3 using <, >, or =. Sketch a number line to justify.

  7. Constructed response

    Draw a horizontal or vertical number line. Plot and label -5/4, 0, and 3/4. Name the step size of your scale and explain the placement.

  8. Multiple select

  9. Graphing and two-part response

  10. Constructed response

    Temperatures are -7/5°C and -2/5°C. Write an inequality comparing them and explain which is warmer.

03 · CHECK

Answers and reasoning

Reveal the teacher answer key
  1. -8 < 0 < 4; unit steps

    Negative -8 is left of or below 0; 4 is right of or above 0. Use equal intervals.

    6.NS.C.6c
  2. =

    -3 = -3; greater numbers lie farther right.

    6.NS.C.7a, 6.NS.C.7b
  3. -6 < 0 < 2; unit steps

    Negative -6 is left of or below 0; 2 is right of or above 0. Use equal intervals.

    6.NS.C.6c
  4. <

    -2 < -1/2; greater numbers lie farther right.

    6.NS.C.7a, 6.NS.C.7b
  5. -2/3 < 0 < 4/3; use steps of 1/3

    Negative -2/3 is left of or below 0; 4/3 is right of or above 0. Use equal intervals.

    6.NS.C.6c
  6. >

    -3/5 > -4/3; greater numbers lie farther right.

    6.NS.C.7a, 6.NS.C.7b
  7. -5/4 < 0 < 3/4; use steps of 1/4

    Negative -5/4 is left of or below 0; 3/4 is right of or above 0. Use equal intervals.

    6.NS.C.6c
  8. B, C - -6 < -4; -4 lies to the right of -6 on a number line.

    Among negatives, the number closer to zero is greater. Thus -4 is warmer and is farther right.

    6.NS.C.7a, 6.NS.C.7b
  9. Leftmost -13/2; midpoint -13/2

    -13/2 = -6 - 1/2 lies halfway between -7 and -6, left of both -6 and 0.

    6.NS.C.6c
  10. -7/5 < -2/5; -2/5°C is warmer

    The greater value is farther right on a number line, even when both are negative.

    6.NS.C.7a, 6.NS.C.7b
