Day 082 · Lesson 07Represent and Graph Ratios

LearnPracticeDaily PDF ↗
Standards 6.RP.A.3a

enVision Topic 5: Understand and Use Ratios and Rates | Spectrum companion Chapter 3

LEARNING TARGET

I can plot equivalent-ratio pairs and explain a point.

01 · LEARN

Build the idea

Put the first quantity on the horizontal axis and the second on the vertical axis. Build a table, label units, and plot ordered pairs. A point (x,y) describes both quantities together.

WORKED EXAMPLE 1 · Constructed response

For every 6 tickets sold, a club earns $2. Make a table for 0, 1, 2, and 3 batches. Plot (tickets, dollars), label axes, and interpret (18, 6).

Step-by-step solution

  1. Put the first quantity on the horizontal axis and the second on the vertical axis.
  2. Build a table, label units, and plot ordered pairs.
  3. Scale both quantities by each batch count
  4. plot horizontal tickets and vertical dollars.
Answer: (0,0), (6,2), (12,4), (18,6); 18 tickets earns $6
WORKED EXAMPLE 2 · Table, graph, and interpretation

A club earns $5 for every 5 tickets. Part A: plot ordered pairs for 0, 1, 2, and 6 batches (tickets, dollars). Part B: explain the meaning of (30, 30).

Step-by-step solution

  1. Put the first quantity on the horizontal axis and the second on the vertical axis.
  2. For each batch count, multiply both 5 and 5 by that count.
  3. Keep tickets horizontal and dollars vertical.
Answer: (0,0), (5,5), (10,10), (30,30); 30 tickets earn $30.
