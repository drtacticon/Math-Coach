Day 123 · Lesson 03Display and Interpret Dot Plots

LearnPracticeDaily PDF ↗
Standards 6.SP.B.4

enVision Topic 8: Display, Describe, and Summarize Data | Spectrum companion Chapter 7

LEARNING TARGET

I can construct and interpret a dot plot on a number line.

01 · LEARN

Build the idea

Draw an equally spaced number line and stack one dot per observation above its value. Repeated values stack vertically. Add an axis label with units and check that the dot count equals the data count.

WORKED EXAMPLE 1 · Constructed response

Reading times in minutes are 7, 8, 8, 9, 9, 10. Draw a labeled dot plot. Check the number of dots.

  1. Draw an equally spaced number line and stack one dot per observation above its value.
  2. Repeated values stack vertically.
  3. Each observation contributes one dot
  4. stack repeated values at their number-line position.
  5. State the result in the form requested: 7: 1 dot; 8: 2 dots; 9: 2 dots; 10: 1 dot; n = 6.
7: 1 dot; 8: 2 dots; 9: 2 dots; 10: 1 dot; n = 6
WORKED EXAMPLE 2 · Data display and numeric entry

A frequency table records books read: 0 books: 1 students; 1: 5; 2: 4; 3: 1. Part A: draw a dot plot. Part B: enter the observation count and explain how to verify it.

  1. Draw an equally spaced number line and stack one dot per observation above its value.
  2. Place one dot per student, not one per distinct value.
  3. Total dots = 1 + 5 + 4 + 1 = 11.
  4. Label the number line books read.
11 students; stacks at 0, 1, 2, 3 have 1, 5, 4, 1 dots.
