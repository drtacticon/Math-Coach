enVision Topic 7: Solve Area, Surface Area, and Volume Problems | Spectrum companion Chapter 6

LEARNING TARGET

I can find pyramid surface area from its triangular faces and base.

01 · LEARN

Build the idea

For a square pyramid, draw one square and four triangles. Each triangle has area base edge × face height / 2. The face height is measured on the triangular face, not vertically inside the solid.

WORKED EXAMPLE 1 · Constructed response

A square pyramid has base edge 6 cm. Each triangular face has perpendicular face height 6 cm. Draw a net and calculate total surface area.

  1. For a square pyramid, draw one square and four triangles.
  2. Each triangle has area base edge × face height / 2.
  3. Base = 36
  4. each triangle = 6 × 6 ÷ 2 = 18
  5. add four triangles to get 108.
  6. State the result in the form requested: 108 cm².
108 cm²
WORKED EXAMPLE 2 · Net reasoning and numeric entry

A square pyramid net has base side 8 cm and four triangular faces, each with perpendicular face height 7 cm. Part A: enter one triangular face area. Part B: enter the entire surface area.

  1. For a square pyramid, draw one square and four triangles.
  2. One face = (8 × 7)/2 = 28.
  3. Four faces total 112.
  4. Add square base area 64.
Face 28 cm²; total 176 cm²
