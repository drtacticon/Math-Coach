enVision Topic 4: Represent and Solve Equations and Inequalities | Spectrum companion Chapter 5

LEARNING TARGET

I can interpret Relationships in Context, and explain and check my reasoning.

01 · LEARN

Build the idea

The independent variable is the input you choose; the dependent variable changes with it. Define both and write the output in terms of the input. A table and graph must show the same rule and units. Choose input values, substitute to find outputs, and write ordered pairs. Label horizontal input and vertical output axes. Plot each pair and interpret a point in the situation.

WORKED EXAMPLE 1 · Constructed response

A shop charges $5 for each of n notebooks. Name the independent and dependent variables and write a cost rule.

Step-by-step solution

  1. The independent variable is the input you choose; the dependent variable changes with it.
  2. Define both and write the output in terms of the input.
  3. The chosen notebook count is the input
  4. multiply it by price and add any fixed fee to get the cost.
Answer: Independent n = notebooks; dependent C = cost; C = 5n
WORKED EXAMPLE 2 · Table completion, equation, and graph

A machine uses 7 liters per hour. Part A: complete the (hours, liters) table: (0, __), (1, __), (2, __). Part B: choose the independent variable and write an equation for L in terms of h. Plot your pairs.

Step-by-step solution

  1. Choose input values, substitute to find outputs, and write ordered pairs.
  2. Hours are the input.
  3. Multiply each hour value by 7 to obtain liters.
  4. Graph hours horizontally and liters vertically.
Answer: (0,0), (1,7), (2,14); independent h; L = 7h
02 · PRACTICE

Your turn

Start with foundations, then apply the idea and explain your reasoning. Select answers below or record them on paper.

  1. Constructed response

    A shop charges $6 for each of n notebooks. Name the independent and dependent variables and write a cost rule.

  2. Constructed response

    For y = 2x, make a table for x = 0, 1, 2, 3. Plot the ordered pairs and label both axes.

  3. Constructed response

    A shop charges $8 for each of n notebooks. Name the independent and dependent variables and write a cost rule.

  4. Constructed response

    For y = 8x + 7, make a table for x = 0, 1, 2, 5. Plot the ordered pairs and label both axes.

  5. Constructed response

    A shop charges $4 for each of n notebooks plus a single $7 delivery fee. Name the independent and dependent variables and write a cost rule.

  6. Constructed response

    For y = 6x + 3, make a table for x = 0, 1, 2, 5. Plot the ordered pairs and label both axes.

  7. Constructed response

    A shop charges $8 for each of n notebooks plus a single $3 delivery fee. Name the independent and dependent variables and write a cost rule. What does the cost at n = 0 mean in this model?

  8. Table completion, equation, and graph

    A machine uses 4 liters per hour. Part A: complete the (hours, liters) table: (0, __), (1, __), (3, __). Part B: choose the independent variable and write an equation for L in terms of h. Plot your pairs.

  9. Table completion, equation, and graph

    A machine uses 2 liters per hour. Part A: complete the (hours, liters) table: (0, __), (1, __), (5, __). Part B: choose the independent variable and write an equation for L in terms of h. Plot your pairs.

  10. Constructed response

    For y = 7x + 6, make a table for x = 0, 1, 2, 3. Plot the ordered pairs and label both axes. Explain what happens to y each time x increases by 1.
