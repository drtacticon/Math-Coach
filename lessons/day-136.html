Day 136 · Lesson 01Connect Rational Numbers, Expressions, and Ratios

LearnPracticeDaily PDF ↗
Standards 6.NS.A.16.NS.C.7a6.NS.C.7b6.EE.A.2c6.RP.A.3a

Cumulative application across enVision Topics 1–8 | Spectrum cross-chapter review

LEARNING TARGET

I can connect Rational Numbers, Expressions, and Ratios, and explain and check my reasoning.

01 · LEARN

Build the idea

If (a/b) ÷ (c/d) = q, then (c/d) × q = a/b. Multiplying by d/c undoes multiplying by c/d, so divide by a nonzero fraction by multiplying by its reciprocal. Simplify the product. A number farther right is greater. Among negative numbers, the value closer to zero is greater. Use a common denominator or familiar benchmarks to compare negative fractions. Replace every variable with its assigned value, using parentheses. Apply the order of operations. In formulas, label the answer with the appropriate measurement units. Multiply both values in a ratio by the same scale factor. Organize pairs in a table and check that every row compares the same quantities in the same order.

WORKED EXAMPLE 1 · Constructed response

Calculate 1/2 ÷ 1/2. Simplify.

Step-by-step solution

  1. Rename the numbers as fractions: 1/2 = 1/2 and 1/2 = 1/2.
  2. Keep the first fraction and multiply by the reciprocal of the second: 1/2 × 2.
  3. Multiply numerators and denominators: (1 × 2) / (2 × 1) = 2/2.
  4. Simplify by dividing top and bottom by 2: 1.
  5. Check the result: 1/2 × 1 = 1/2, so the quotient is correct.
Answer: 1
WORKED EXAMPLE 2 · Multiple select

A recipe uses 5 cups oats for 3 cups seeds. Select all (oats, seeds) pairs that keep this ratio.

A. (26, 15)

B. (15, 9)

C. (10, 7)

D. (10, 6)

Step-by-step solution

  1. Multiply both values in a ratio by the same scale factor.
  2. Equivalent ratios multiply both quantities by the same factor.
  3. A uses 2
  4. B uses 3.
  5. C and D change only one scaled quantity.
Answer: B, D - (15, 9); (10, 6)
02 · PRACTICE

Your turn

Start with foundations, then apply the idea and explain your reasoning. Select answers below or record them on paper.

  1. Constructed response

    Calculate 1/4 ÷ 1/2. Simplify.

  2. Constructed response

    Compare -2 ___ -7 using <, >, or =. Sketch a number line to justify.

  3. Constructed response

    Evaluate 4x + 3 for x = 4.

  4. Constructed response

    A mix uses 3 cups of oats for 7 cups of seeds. Complete the table (oats, seeds): (3, 7), (6, ___), (12, ___).

  5. Constructed response

    Calculate 1/2 ÷ 1. Simplify.

  6. Constructed response

    Compare -3/2 ___ -7/5 using <, >, or =. Sketch a number line to justify.

  7. Constructed response

    A rectangle has length x + 8 and width 2. Use A = lw to write its area expression and find A when x = 5.

  8. Multiple select

    A recipe uses 3 cups oats for 4 cups seeds. Select all (oats, seeds) pairs that keep this ratio.

  9. Multiple choice

    Calculate 2/3 ÷ 1/5. Simplify and explain why your answer is reasonable. Select one answer, then justify it with a model or calculation.

  10. Constructed response

    Temperatures are -7/3°C and -5/2°C. Write an inequality comparing them and explain which is warmer.

03 · CHECK

Answers and reasoning

Reveal the teacher answer key
  1. 1/2

    1/4 ÷ 1/2 = 1/4 × 2 = 1/2.

    6.NS.A.1
  2. >

    -2 > -7; greater numbers lie farther right.

    6.NS.C.7a, 6.NS.C.7b
  3. 19

    Substitute first: 4 × 4 + 3 = 19.

    6.EE.A.2c
  4. 14; 28

    Multiply both parts by 2 and by 4.

    6.RP.A.3a
  5. 1/2

    1/2 ÷ 1 = 1/2 × 1 = 1/2.

    6.NS.A.1
  6. <

    -3/2 < -7/5; greater numbers lie farther right.

    6.NS.C.7a, 6.NS.C.7b
  7. A = 2(x + 8); 26 square units

    Substitute x = 5: 2(5 + 8) = 26.

    6.EE.A.2c
  8. A, C - (9, 12); (6, 8)

    Equivalent ratios multiply both quantities by the same factor. A uses 2; B uses 3. C and D change only one scaled quantity.

    6.RP.A.3a
  9. A - 10/3

    2/3 ÷ 1/5 = 2/3 × 5 = 10/3.

    6.NS.A.1
  10. -7/3 > -5/2; -7/3°C is warmer

    The greater value is farther right on a number line, even when both are negative.

    6.NS.C.7a, 6.NS.C.7b
