03 · CHECK

Answers and reasoning

Reveal the teacher answer key
  1. 3 × 3 = 9

    The exponent counts 2 factors of 3; multiply all factors.

    6.EE.A.1
  2. 18

    Use parentheses and exponents first, then × and ÷ left to right, then + and -. Result: 18.

    6.EE.A.1, 6.EE.A.2c
  3. 5

    Common factors: 1, 5; greatest is 5.

    6.NS.B.4a
  4. 6

    The first positive multiple shared by 2 and 6 is 6.

    6.NS.B.4b
  5. No; left side = 28

    3 × 7 + 7 = 28; compare with 25.

    6.EE.B.5
  6. x = 2

    Subtract 3 on both sides. Then x = 2; substitution gives 5 on each side.

    6.EE.B.7
  7. x = 19/2

    Add 7 on both sides. Then x = 19/2; substitution gives 5/2 on each side.

    6.EE.B.7
  8. x = 3/2

    Divide by 7 on both sides. Then x = 3/2; substitution gives 21/2 on each side.

    6.EE.B.7
  9. x = 7/2

    Subtract 4 on both sides. Then x = 7/2; substitution gives 15/2 on each side.

    6.EE.B.7
  10. x = 7/2

    Multiply by 8 on both sides. Then x = 7/2; substitution gives 7/16 on each side.

    6.EE.B.7
  11. 7x = 28; x = 4 m

    Divide the total by 7: 28 ÷ 7 = 4.

    6.EE.B.6, 6.EE.B.7
  12. C, D - 12 is an allowed membership count.; n ≥ 12

    At least includes the boundary, so n ≥ 12. On a real number line use a closed point and shade right; actual member counts are whole numbers.

    6.EE.B.8
  13. C, D - n ≥ 15; 15 is an allowed membership count.

    At least includes the boundary, so n ≥ 15. On a real number line use a closed point and shade right; actual member counts are whole numbers.

    6.EE.B.5, 6.EE.B.8
  14. A, C - n ≥ 42; 42 is an allowed membership count.

    At least includes the boundary, so n ≥ 42. On a real number line use a closed point and shade right; actual member counts are whole numbers.

    6.EE.B.8
  15. C, D - 25 is an allowed membership count.; n ≥ 25

    At least includes the boundary, so n ≥ 25. On a real number line use a closed point and shade right; actual member counts are whole numbers.

    6.EE.B.5, 6.EE.B.8
  16. (0,0), (1,4), (4,16); independent h; L = 4h

    Hours are the input. Multiply each hour value by 4 to obtain liters. Graph hours horizontally and liters vertically.

    6.EE.C.9
  17. (0,0), (1,3), (6,18); independent h; L = 3h

    Hours are the input. Multiply each hour value by 3 to obtain liters. Graph hours horizontally and liters vertically.

    6.EE.C.9
  18. (0,0), (1,6), (4,24); independent h; L = 6h

    Hours are the input. Multiply each hour value by 6 to obtain liters. Graph hours horizontally and liters vertically.

    6.EE.C.9
  19. C, D - 6; 7

    Subtract 7 conceptually: x must exceed 5. Equality at 5 fails because the inequality is strict.

    6.EE.B.5
  20. B, D - 18/4; 9/2

    Use the inverse operation on both sides. The solution is 9/2; the doubled numerator and denominator name the same value. Substitution verifies the solution.

    6.EE.B.7
