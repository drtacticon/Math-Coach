Practice answer key

Show answers and reasoning
  1. 4 × 4 × 4 × 4 = 256

    The exponent counts 4 factors of 4; multiply all factors.

  2. 25

    Use parentheses and exponents first, then × and ÷ left to right, then + and -. Result: 25.

  3. 4

    Common factors: 1, 2, 4; greatest is 4.

  4. 6

    The first positive multiple shared by 3 and 2 is 6.

  5. No; left side = 38

    5 × 7 + 3 = 38; compare with 33.

  6. x = 6

    Subtract 4 on both sides. Then x = 6; substitution gives 10 on each side.

  7. x = 5

    Add 4 on both sides. Then x = 5; substitution gives 1 on each side.

  8. x = 5/2

    Divide by 7 on both sides. Then x = 5/2; substitution gives 35/2 on each side.

  9. x = 3/2

    Subtract 4 on both sides. Then x = 3/2; substitution gives 11/2 on each side.

  10. x = 7/2

    Multiply by 4 on both sides. Then x = 7/2; substitution gives 7/8 on each side.

  11. 6x = 48; x = 8 m

    Divide the total by 6: 48 ÷ 6 = 8.

  12. C, D - n ≥ 30; 30 is an allowed membership count.

    At least includes the boundary, so n ≥ 30. On a real number line use a closed point and shade right; actual member counts are whole numbers.

  13. C, D - n ≥ 6; 6 is an allowed membership count.

    At least includes the boundary, so n ≥ 6. On a real number line use a closed point and shade right; actual member counts are whole numbers.

  14. A, C - n ≥ 24; 24 is an allowed membership count.

    At least includes the boundary, so n ≥ 24. On a real number line use a closed point and shade right; actual member counts are whole numbers.

  15. A, C - 36 is an allowed membership count.; n ≥ 36

    At least includes the boundary, so n ≥ 36. On a real number line use a closed point and shade right; actual member counts are whole numbers.

  16. (0,0), (1,5), (4,20); independent h; L = 5h

  17. (0,0), (1,3), (3,9); independent h; L = 3h

  18. (0,0), (1,3), (4,12); independent h; L = 3h

  19. B, C - 3; 4

    Subtract 5 conceptually: x must exceed 2. Equality at 2 fails because the inequality is strict.

  20. A, C - 5/2; 10/4

    Use the inverse operation on both sides. The solution is 5/2; the doubled numerator and denominator name the same value. Substitution verifies the solution.
