Example for question 16

Point P is (-5, 6). Select all correct reflections.

  • A. Across the x-axis: (5, 6).
  • B. Across the x-axis: (-5, -6).
  • C. Across the y-axis: (5, 6).
  • D. Across both axes: (-5, 6).
  1. The x-axis reflection changes y only
  2. the y-axis reflection changes x only.
  3. Across both gives (5, -6).

Answer: B, C - Across the x-axis: (-5, -6).; Across the y-axis: (5, 6).
