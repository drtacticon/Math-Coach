# Math Coach

Arizona Grade 6 mathematics in 140 daily lessons and assessments.

## Browse

- Website: https://drtacticon.github.io/Math-Coach/
- Lesson index: `index.html`
- Direct example: `lessons/day-031.html#lesson-top`

Every day has a sticky top navigation bar with previous/next day arrows, a day selector, and an index link. The index links directly to each lesson’s top anchor. The first and last days disable the unavailable arrow.

112 lesson days include standards, a learning target, lecture notes, two worked examples, ten classwork problems, and an expandable answer key. Nineteen quizzes and nine unit tests retain the original 20% review policy. The `downloads/daily` folders contain all 140 teacher packets. Full course PDFs, pacing, and standards mapping are under `downloads`.

## Run locally

This is a static HTML/CSS/JavaScript website with no build step. Open `index.html`, or serve the repository root with any static web server. All internal paths are relative for GitHub Pages project hosting.

## Publish

GitHub Pages serves the `main` branch at the repository root. No account information, API credentials, or student records are included. The optional resume link uses only browser-local storage.

## Sources

The curriculum uses the supplied Arizona sixth-grade standards placemat. The teacher guide identifies source links and optional chapter-level Spectrum Math companion mapping from publisher previews. All curriculum wording, examples, and exercises are original. This project is independent of Carson Dellosa Education.
